# 考研英语（二）翻译 Part C — 复习指南

> 15 分，1 段英文 → 中文。考**理解 + 中文习惯**，不是背单词表。

---

## 一、复习流程（单篇约 25 分钟）

1. **限时翻译**：只看 `translation/{年}.md` 英文原文，不看参考译文。  
2. **对照批改**：标漏译、错译、拗口处。  
3. **记 3–5 点**：长句怎么切、术语怎么译、哪类结构总错。  
4. **隔天重译**错句，不看参考再写一遍。

---

## 二、高频易错类型

| 类型 | 示例思路 |
|------|----------|
| 长句切分 | 英语多从句 → 中文多短句，按意群断句 |
| 被动语态 | 常改主动或「由…所…」不宜堆砌「被」 |
| 抽象名词 | development → 发展；approach → 方法/途径（看语境） |
| 习语/比喻 | pop into my mind → 跃入脑海；不宜字对字 |
| 专有名词 | 作品名、机构：用通用译名或加原文 |
| 逻辑词 | but / however / moreover 要显化，避免漏转折 |

---

## 三、评分自检（自评用）

- [ ] 要点是否译全（无漏段、漏并列）  
- [ ] 有无误译（反义、偷换主语）  
- [ ] 中文是否通顺（朗读一遍）  
- [ ] 术语、数字、时间是否准确  
- [ ] 有无多余增译（没把握可直译）

---

## 四、与阅读词汇库的关系

阅读 `EN_Words/{年}/` 里的词**有助于**翻译，但翻译更依赖：

- 句法（定语从句、插入语、形式主语）  
- 篇章衔接（指代、省略）  
- 中文润色（避免翻译腔）

建议：**阅读词汇照常背；翻译单独用本目录逐年练。**
