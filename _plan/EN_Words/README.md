## 建议复习流程

1. **读原文**：打开 `{年}.txt`，通读对应 Text，标出不认识的词。  
2. **背词汇**：对照 `{年}-textN-vocab.md`，先看文首 **速查总表**，再记「原文语境」列。  
3. **自测**：遮住中文，做文末 **复习小测**。  
4. **总复习**：考前用 `{年}-vocab-all.md` 或按上表「必记搭配」过一遍。  
5. **主动回忆**（推荐）：先想释义 → 再对照 → 第 2、7 天重复（间隔复习）。

### 三遍法（单篇约 15 分钟）

| 遍 | 做法 |
|----|------|
| 第 1 遍 | 读 `txt` + 标记生词 + 对照 vocab 记搭配 |
| 第 2 遍 | 遮住中文，看英文与例句说释义 |
| 第 3 遍 | 做 vocab 文末小测，不会的打勾，隔天再背 |

## 更新与抓取

从网站重新抓取某年原文（需网络）：

```bash
cd _plan/EN_Words/scripts
# 单年（需先将页面保存为 markdown 或运行 fetch 后传入）
python3 scrape_english2.py /path/to/page.md 2026

# 批量（2013–2026，需 agent-tools 中已有抓取文件）
bash batch_scrape.sh
```

**说明**：

- 2010–2012 原文经人工校正；2013–2026 由脚本从网站提取，**可能残留 OCR 错字**。  
- 词汇表按真题语境编写，与原文段落对应；若发现错字可先改 `{年}.txt` 再反馈。
