## 题目 3 前驱 / 后继（floor & ceiling）

**题**：

- **floor**：树中 `≤ K` 的最大关键字（不存在则标记无）
- **ceiling**：树中 `≥ K` 的最小关键字（不存在则标记无）

**要求**：能否 O(h)？`K=6` 时 floor、ceiling 各是多少？

**文件**：`p03_floorCeiling.c`

**速答**：`K=5` → floor=5, ceiling=5；`K=6` → floor=5, ceiling=7。

## 参考答案摘要

### 题 1

沿查找路径维护 `best`：`diff` 更小则更新；`K < val` 走左，否则走右；`K == val` 可结束。时间 O(h)，空间 O(1)。

### 题 2

与 408 原题相同：路径上更新 `minDiff` 与输出列表；`diff < minDiff` 清空列表；`diff == minDiff` 追加；`K == val` 则 `break`。

### 题 3

查找 `K` 时维护「最后一个小于 K 的候选」与「第一个大于 K 的候选」；或标准 BST 查找 + 前驱后继。

### 题 4

- `node->val > R`：只走左
- `node->val < L`：只走右
- 否则：中序 左 → 根 → 右（两侧可剪枝）

### 题 5

沿找 `K` 的路径：走右时当前结点及左子树均 `< K`；走左时只计左子树。无 size 字段时可用中序 O(n) 或维护子树规模 O(h)。

### 题 6

先定区间 `[L,R]`，在区间内用题 2 的「维护最小差 + 收集并列」；最坏 O(n)。

## 408 答题模板（题 2）

**（1）基本思想（4 分）**

利用 BST 性质，从根沿查找 `K` 的路径向下；在每个访问结点计算 `|key-K|`，维护当前最小差值及对应结点集合；更优则清空重记，并列则追加；若 `K` 等于当前结点关键字则差为 0，可结束。时间 O(h)，辅助空间 O(1)（不计输出数组）。

**（2）C 描述（8 分）**

见 `../findClosestAll.c`。
